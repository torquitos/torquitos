## 🚧 Proyectos destacados

### [Dinámicas Razam](https://torquitos.github.io/informacion-dinamicas-razam)
Sitio web para un negocio familiar de rifas y sorteos. Panel de administración vía URL hash, resultados persistentes con `localStorage`, y despliegue en GitHub Pages.

### Asset Management System
Sistema de gestión de activos físicos e inventario. Arquitectura modular (HTML/CSS/JS separados), página de detección de hardware, y navegación dinámica con JavaScript puro.

### Mini-Reproductor Spotify
Widget flotante para Windows construido en Python con `customtkinter`. Integración con Spotify vía `winsdk` sin API key, portada del álbum en tiempo real, y controles de reproducción.
